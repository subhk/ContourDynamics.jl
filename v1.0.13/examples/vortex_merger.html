Vortex Merger ​

Two identical nested vortices are placed three radii apart, following the symmetric vortex merger setup in Fig. 13 of Dritschel (1988). Each vortex uses two contour levels to approximate ω(r)=2π(1−r2).

What to look for:

  • nested contours stretch and exchange filaments

  • surgery reconnects nearby segments

  • the final state has fewer contours than the initial state

The topological reconnection used for this partial-merger calculation is described in Dritschel (1988) and Dritschel (1989). The full script in examples/vortex_merger.jl writes snapshots, a final figure, an MP4 animation, and vortex_merger_diagnostics.csv with contour count, node count, area, circulation drift, and energy drift for validation.

julia
julia> using ContourDynamics

julia> R = 1.0
1.0

julia> sep = 3.0 * R
3.0

julia> nlevels = 2
2

julia> N = 32
32

julia> pv_jump = 2π / nlevels
3.141592653589793

julia> radii = [R * sqrt(j / nlevels) for j in 1:nlevels]
2-element Vector{Float64}:
 0.7071067811865476
 1.0

julia> nested_vortex(cx) = [circular_patch(r, N, pv_jump; cx=cx) for r in radii]
nested_vortex (generic function with 1 method)

julia> initial_contours = PVContour{Float64}[]
PVContour{Float64}[]

julia> append!(initial_contours, nested_vortex(-sep / 2))
2-element Vector{PVContour{Float64}}:
 PVContour{Float64}: 32 nodes, Δq = 3.141592653589793, closed, centered at (-1.50, 0.00)
 PVContour{Float64}: 32 nodes, Δq = 3.141592653589793, closed, centered at (-1.50, -0.00)

julia> append!(initial_contours, nested_vortex(+sep / 2))
4-element Vector{PVContour{Float64}}:
 PVContour{Float64}: 32 nodes, Δq = 3.141592653589793, closed, centered at (-1.50, 0.00)
 PVContour{Float64}: 32 nodes, Δq = 3.141592653589793, closed, centered at (-1.50, -0.00)
 PVContour{Float64}: 32 nodes, Δq = 3.141592653589793, closed, centered at (1.50, -0.00)
 PVContour{Float64}: 32 nodes, Δq = 3.141592653589793, closed, centered at (1.50, 0.00)

julia> prob = Problem(; contours=initial_contours, dt=0.005,
                        surgery=SurgeryParams(1e-4, 0.01, 0.15, 1e-8, 10))
Problem
├── ContourProblem{EulerKernel, UnboundedDomain, Float64}
├── RK4Stepper{Float64}: dt = 0.005
└── surgery: δ=0.0001, μ=0.01, Δ_max=0.15, every 10 steps

julia> circulation0 = circulation(prob)
29.41892747675211

julia> evolve!(prob; nsteps=5)
Problem
├── ContourProblem{EulerKernel, UnboundedDomain, Float64}
├── RK4Stepper{Float64}: dt = 0.005
└── surgery: δ=0.0001, μ=0.01, Δ_max=0.15, every 10 steps

julia> final_contours = materialize_contours(prob)
4-element Vector{PVContour{Float64}}:
 PVContour{Float64}: 32 nodes, Δq = 3.141592653589793, closed, centered at (-1.50, -0.02)
 PVContour{Float64}: 32 nodes, Δq = 3.141592653589793, closed, centered at (-1.50, -0.02)
 PVContour{Float64}: 32 nodes, Δq = 3.141592653589793, closed, centered at (1.50, 0.02)
 PVContour{Float64}: 32 nodes, Δq = 3.141592653589793, closed, centered at (1.50, 0.02)

julia> println("Final: $(length(final_contours)) contour(s), $(total_nodes(prob)) nodes")
Final: 4 contour(s), 128 nodes

julia> println("Relative circulation change: $(round(abs(circulation(prob) - circulation0) / abs(circulation0); digits=8))");
Relative circulation change: 2.3e-7
