Two-Layer QG ​

Two identical circular upper-layer vortex patches merge in a two-layer quasi-geostrophic system. The physical setup is Figure 19 of Polvani, Zabusky & Flierl (1989): unit radius and PV jump, initial centroid distance di=2.2, depth ratio δ=0.2, and γ=R/Ld=5. The lower layer has uniform geostrophic PV.

What to look for:

  • how the coupling matrix is defined

  • how a multi-layer problem is constructed

  • energy and circulation staying nearly constant over the run

Polvani et al. write the Phillips stretching operator as

γ2[−11δ−δ].

The package uses its symmetric similar form, whose off-diagonal entries are γ2δ; this leaves the upper-layer inversion unchanged and enables the modal solver. The short docs run below uses fewer nodes and steps than the paper. The full script in examples/two_layer_qg.jl writes snapshots and media under examples/output/two_layer_qg/, but is likewise a literature-derived numerical adaptation rather than an exact reproduction of the paper's time integration.

julia
julia> using ContourDynamics, StaticArrays

julia> N = 64
64

julia> R, pv = 1.0, 1.0
(1.0, 1.0)

julia> depth_ratio = 0.2
0.2

julia> gamma = 5.0
5.0

julia> initial_distance = 2.2
2.2

julia> # Symmetric form of the two-layer Phillips stretching operator
       sqrt_delta = sqrt(depth_ratio)
0.4472135954999579

julia> Ld = SVector(1.0 / (gamma * sqrt(1 + depth_ratio)))
1-element StaticArraysCore.SVector{1, Float64} with indices SOneTo(1):
 0.18257418583505539

julia> coupling = gamma^2 * SMatrix{2,2}(-1.0, sqrt_delta,
                                          sqrt_delta, -depth_ratio)
2×2 StaticArraysCore.SMatrix{2, 2, Float64, 4} with indices SOneTo(2)×SOneTo(2):
 -25.0     11.1803
  11.1803  -5.0

julia> # Figure 19: two upper-layer vortices and uniform lower-layer PV
       c_left = circular_patch(R, N, pv; cx=-initial_distance / 2)
PVContour{Float64}: 64 nodes, Δq = 1.0, closed, centered at (-1.10, -0.00)

julia> c_right = circular_patch(R, N, pv; cx=initial_distance / 2)
PVContour{Float64}: 64 nodes, Δq = 1.0, closed, centered at (1.10, -0.00)

julia> prob = Problem(;
           kernel   = :multilayer_qg,
           dt       = 0.01,
           Ld       = Ld,
           coupling = coupling,
           layers   = ([c_left, c_right], PVContour{Float64}[]),
           surgery  = :none,
       )
Problem
├── MultiLayerContourProblem{2, UnboundedDomain, Float64}
├── RK4Stepper{Float64}: dt = 0.01
└── surgery: disabled

julia> energy0 = energy(prob)
0.03361537161182468

julia> circulation0 = circulation(prob)
6.273096981091878

julia> evolve!(prob; nsteps=5)
Problem
├── MultiLayerContourProblem{2, UnboundedDomain, Float64}
├── RK4Stepper{Float64}: dt = 0.01
└── surgery: disabled

julia> println("Energy: $(round(energy(prob); digits=6))  (change: $(round(abs(energy(prob)-energy0)/abs(energy0); digits=8)))")
Energy: 0.033615  (change: 2.9e-6)

julia> println("Circulation: $(round(circulation(prob); digits=6))  (change: $(round(abs(circulation(prob)-circulation0)/abs(circulation0); digits=8)))");
Circulation: 6.273097  (change: 1.0e-8)

Reference:

  • Polvani, L.M., Zabusky, N.J. & Flierl, G.R. (1989). Two-layer geostrophic vortex dynamics. Part 1. Upper-layer V-states and merger. J. Fluid Mech. 205, 215–242. doi:10.1017/S0022112089002016
